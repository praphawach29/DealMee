# DealMee video

คลิปโปรโมต DealMee แนวตั้ง 1080×1920 สำหรับ Facebook Reels / TikTok
ภาพเป็นฟังก์ชันของเวลา (`window.render(t)` ใน `template.html`) เรนเดอร์ทีละเฟรมด้วย Chromium แล้วต่อด้วย ffmpeg
เพลงและเสียงเอฟเฟคแต่งด้วยโค้ด (`music.py` จาก repo checkmee-video) ไม่ติดลิขสิทธิ์ · ไม่มีเสียงพูด เจ้าของพากย์เองจากบทใน `finals/*-voiceover.md`

## ไฟล์

```
template.html   หน้าตาทุกฉาก: ฉากเปิด (hook) · มือถือ+แชท · การ์ดแจ้งเตือน · หน้าต่างหลังบ้าน · ฉากปิด
clips.js        คลิปฟีเจอร์ 01–06 (ข้อความ เวลา บทพากย์)
overview.js     คลิปภาพรวม 1 นาที: 7 ช่วงต่อกันด้วยการจาง 0.4 วิ
pipeline.js     เรนเดอร์ภาพ → cues → เพลง → รวมไฟล์ → บทพากย์ .md/.srt
music.py        เพลง + เสียง pop/แตะ/whoosh/กริ๊ง/คีย์บอร์ด/ปิดแบรนด์ ตามเวลาใน cues
assets/         โลโก้ (จาก public/logos) และฟอนต์ IBM Plex Sans Thai (OFL)
finals/         คลิปที่ส่งแล้ว + บทพากย์ + ซับ + แคปชั่นสำหรับโพสต์
PLAN.md         แผนคอนเทนต์ 4 สัปดาห์
```

## ทำคลิป

```bash
cd video
npm install
pip install numpy                         # music.py
export CHROME_PATH=/path/to/chrome        # ถ้าไม่ใช่เครื่องคลาวด์ของ Claude
node pipeline.js shorts                   # คลิปใน clips.js → out/
node pipeline.js overview                 # คลิปภาพรวม → out/
```

คลิปใหม่: เพิ่ม object ใน `clips.js` (ดูตัวอย่างที่มีอยู่) · `msgs` คือข้อความในแชทตามเวลา `side: 'user'|'bot'|'sys'`,
`kind: 'qr'|'slip'` สำหรับการ์ด QR/สลิป · `overlays` คือการ์ดแจ้งเตือน (`notify`) หรือหน้าต่างหลังบ้าน (`panel`) ·
`chime: true` ใส่เสียงกริ๊งตอนข้อความนั้นขึ้น · `vo` คือบทพากย์ของช่วงนั้น
ก่อนเรนเดอร์จริง ดูภาพนิ่งหลายจุด (รวมช่วงเปลี่ยนฉาก) ให้แน่ใจว่าตัวหนังสือไทยไม่ขาดบรรทัดกลางคำ

## กติกาเนื้อหา
- พูดได้เฉพาะสิ่งที่ระบบทำจริง (ดู `docs/sales/kb-bot/`) ห้าม "ตอบถูก 100%" "ปิดการขายได้ทุกแชท"
- ช่องทางที่โปรโมตได้คือ LINE OA · Messenger ยังเป็นช่วงทดลอง (โปรโมตได้หลังแอป Meta ผ่าน App Review) · ห้ามพูดถึง TikTok Shop / Shopee / Instagram / ไลฟ์สด
- ร้าน ลูกค้า เบอร์โทร เป็นข้อมูลสมมติ เบอร์ใส่ xxx · QR ในคลิปเป็นลายตกแต่ง สแกนไม่ได้
- ห้ามรีวิวหรือคำชมที่แต่งขึ้น ใช้ได้เฉพาะรีวิวจริงที่ร้านอนุญาต
- โซน TikTok: ตัวหนังสือสำคัญอยู่ช่วง y 150–1520 และห่างขอบขวา 150px
