# DealMee คู่มือตั้งค่าร้าน (สำหรับร้านที่ใช้อยู่)

## เชื่อม LINE OA กับ DealMee ยังไง
1. เข้า LINE Developers (developers.line.biz) เลือก channel ของ LINE OA ร้าน แท็บ Messaging API
2. ออก Channel access token (long-lived) แล้วคัดลอก และคัดลอก Channel secret จากแท็บ Basic settings
3. ใน DealMee ไปที่ ตั้งค่าบอท แท็บช่องทางแชท วาง Channel Access Token และ Channel Secret แล้วบันทึก
4. คัดลอก Webhook URL จากหน้าเดียวกัน ไปวางที่ Webhook URL ใน LINE Developers กด Verify และเปิด Use webhook
5. ใน LINE Official Account Manager ปิดข้อความตอบกลับอัตโนมัติของ LINE เอง ไม่งั้นลูกค้าจะได้คำตอบซ้อน
ทักแชท LINE OA ของร้านเพื่อทดสอบได้เลย

## เชื่อม LINE แล้วบอทไม่ตอบ
ลองเช็คตามนี้
1. Webhook URL ใน LINE Developers ตรงกับที่ DealMee ให้ กด Verify แล้วขึ้น Success และเปิด Use webhook แล้ว
2. Channel Access Token และ Channel Secret ถูกต้อง ไม่มีช่องว่างเกิน ถ้าออก token ใหม่ต้องมาวางใน DealMee ใหม่
3. ปิดข้อความตอบกลับอัตโนมัติของ LINE OA แล้ว
4. แชทนั้นไม่ได้อยู่ในโหมดแอดมินตอบเอง (ถ้าใช่ สลับกลับเป็นโหมด AI ในเมนูกล่องข้อความ)
5. โควตาข้อความ AI ยังไม่หมด และไม่ได้ตั้งเวลาทำการให้บอทเงียบในช่วงนั้น
ถ้ายังไม่ได้ ฝากชื่อร้านให้ทีมงานตรวจ

## เชื่อม Facebook Messenger ยังไง
ใช้การสร้าง Meta App ของร้านเอง ทำครั้งเดียว
1. สร้างแอปที่ developers.facebook.com เพิ่มผลิตภัณฑ์ Messenger แล้วเชื่อมเพจของร้าน
2. คัดลอก Page ID และออก Page Access Token
3. ใน DealMee แท็บช่องทางแชท ส่วน Facebook ใส่ Page ID, Page Access Token และ App Secret (แนะนำให้ใส่ เพื่อกันข้อความปลอม) แล้วบันทึก
4. คัดลอก Callback URL และ Verify Token จาก DealMee ไปใส่ในหน้าตั้งค่า Webhooks ของ Messenger แล้วเลือกรับ messages และ messaging_postbacks
ระหว่างแอปยังเป็น Development Mode จะทดสอบได้เฉพาะบัญชีที่เป็นแอดมินของแอป ถ้าติดขั้นไหน ทีมงานช่วยได้

## ใส่สินค้ายังไง
ไปที่เมนูสินค้า กดเพิ่มสินค้า ใส่ชื่อ ราคา สต็อก หมวด รายละเอียด และรูป
ใส่ราคาและสต็อกให้ตรงเสมอ เพราะบอทใช้ข้อมูลนี้ตอบลูกค้าและสร้างออเดอร์
เมนูสินค้าและออเดอร์จะแสดงสำหรับร้านประเภทค้าปลีกและร้านอาหาร ร้านบริการใช้เมนูบริการและการจองแทน

## ใส่คลังความรู้ยังไง
ไปที่เมนูคลังความรู้ เลือกนำเข้าไฟล์ ใส่ลิงก์เว็บไซต์ หรือเพิ่มคำถามคำตอบเอง
แนะนำให้เขียนหัวข้อเป็นคำถามที่ลูกค้าพิมพ์จริง เช่น "ส่งกี่วันถึง" "เปลี่ยนไซซ์ได้ไหม" บอทจะหาคำตอบเจอง่ายขึ้น
นำเข้าไฟล์ชื่อเดิมซ้ำ ระบบจะแทนที่ข้อมูลเก่าให้

## ตั้งชื่อและบุคลิกบอทยังไง
ที่หน้าตั้งค่าบอท ตั้งชื่อบอท เลือกบุคลิก (ผู้ชายหรือผู้หญิง สุภาพหรือเป็นกันเอง) เขียนข้อความทักทายลูกค้าใหม่ คำอธิบายร้าน และกฎที่อยากให้บอททำตาม
แล้วลองคุยกับบอทด้วยปุ่ม "ทดสอบแชทจำลอง" ในหน้าตั้งค่าบอทก่อนเปิดใช้จริง

## ตั้งค่าการชำระเงินและค่าส่งยังไง
ไปที่ตั้งค่าบอท แท็บการชำระเงิน & จัดส่ง ใส่เลขพร้อมเพย์และชื่อบัญชี บัญชีธนาคาร เปิดหรือปิดเก็บเงินปลายทาง และตั้งค่าส่งแต่ละโซน
ถ้าจะใช้ key ตรวจสลิปของร้านเอง เลือกผู้ให้บริการ (Thunder, EasySlip, SlipOK) แล้วใส่ key ในหน้าเดียวกัน

## ส่งของแล้ว แจ้งเลขพัสดุให้ลูกค้ายังไง
1. ไปที่เมนูออเดอร์ หาออเดอร์ที่ส่งแล้ว กดปุ่ม "ใส่เลขพัสดุ"
2. เลือกขนส่ง ใส่เลขพัสดุ และวางลิงก์ติดตามที่ขนส่งให้มา (ถ้ามี)
3. ติ๊ก "ส่งเลขพัสดุให้ลูกค้าในแชททันที" แล้วกดบันทึก
ออเดอร์จะเปลี่ยนเป็นจัดส่งแล้ว และลูกค้าได้ข้อความเลขพัสดุใน LINE หรือ Messenger ที่สั่งซื้อ ถ้าออเดอร์ไม่ได้มาจากแชท ระบบบันทึกเลขพัสดุให้ แต่ไม่ได้ส่งข้อความ
ใส่ผิดกด "แก้เลขพัสดุ" แล้วบันทึกใหม่ได้

## ตั้งเพดานสินค้าราคาสูงยังไง
ไปที่เมนูเครื่องมือ การ์ดสินค้าราคาสูง เลือกเพดานราคา (ปิด 3,000 5,000 10,000 20,000 50,000 หรือ 100,000 บาท) สินค้าที่ราคาถึงเพดาน บอทจะส่งต่อให้แอดมินปิดการขาย

## ผูก LINE แอดมินเพื่อรับแจ้งเตือนยังไง
1. เชื่อม LINE OA ของร้านให้เรียบร้อยก่อน
2. ไปที่ ตั้งค่าบอท แท็บช่องทางแชท การ์ดการแจ้งเตือนแอดมินผ่าน LINE
3. ดูว่าการ์ดบอกว่า QR จะเปิดแชทกับ LINE OA ของร้านถูกตัว แล้วสแกน QR ด้วย LINE ส่วนตัวของแอดมิน
4. LINE จะเปิดแชทกับ OA ของร้านพร้อมคำสั่ง /admin-link ตามด้วยรหัส กดส่ง
5. บอทตอบว่าเชื่อมต่อสำเร็จ แล้วกดปุ่มทดสอบส่งแจ้งเตือนในหน้าเว็บได้
ถ้าบอทตอบว่ารหัสไม่ถูกต้อง ให้เช็คว่าแชทที่เปิดขึ้นเป็น LINE OA ของร้านนี้ (ชื่อตรงกับที่การ์ดบอก) แล้วกดรีเฟรชสถานะในการ์ดและสแกน QR อีกครั้ง

## เปลี่ยนแอดมินที่รับแจ้งเตือนยังไง
ในการ์ดการแจ้งเตือนแอดมิน กดยกเลิก แล้วให้แอดมินคนใหม่สแกน QR ด้วย LINE ส่วนตัวของเขา รับแจ้งเตือนได้ 1 คนต่อร้าน

## ไม่ได้รับแจ้งเตือนทาง LINE
1. เช็คว่าการ์ดการแจ้งเตือนแอดมินขึ้นว่าเชื่อมต่อแล้ว และกดทดสอบส่งแจ้งเตือนดู
2. เช็คว่าเปิดสวิตช์แจ้งเตือนแอดมินไว้
3. LINE ส่วนตัวของแอดมินต้องไม่บล็อก LINE OA ของร้าน
4. โควตาข้อความของ LINE OA ร้านต้องยังไม่หมด เพราะแจ้งเตือนนับเป็นข้อความที่ร้านส่งออก (push)

## หยุดบอทชั่วคราว หรือให้บอทกลับมาตอบ
ในเมนูกล่องข้อความ กดสลับแชทนั้นเป็นโหมดแอดมินหรือโหมด AI ได้
เมื่อแอดมินตอบผ่านเมนูกล่องข้อความ บอทหยุดตอบแชทนั้น 1 ชั่วโมงเอง แล้วกลับมาตอบเมื่อครบเวลา
ฝั่งลูกค้าพิมพ์ "ขอคุยกับแอดมิน" เพื่อเรียกคน หรือ /ai เพื่อให้บอทกลับมาตอบ
ถ้าอยากปิดบอททั้งร้าน ปิดสวิตช์ตอบอัตโนมัติในเมนูเครื่องมือ หรือตั้งเวลาทำการ

## ดูยอดข้อความที่ใช้ไปและวันหมดอายุที่ไหน
ที่เมนูแพ็กเกจและการชำระเงิน แสดงแพ็กเกจปัจจุบัน วันหมดอายุ ยอดในกระเป๋า ข้อความ AI และตรวจสลิปที่ใช้ไป แพ็กเสริมที่เหลือ และใบเสร็จการเติมเงิน

## เติมเงินแล้วยอดไม่เข้า
ถ้าสลิปตรวจอัตโนมัติไม่ผ่าน ยอดจะรอทีมงานตรวจและอนุมัติ ปกติไม่นาน
ถ้ารอนานหรือสงสัย ฝากชื่อร้าน ยอดเงิน และเวลาที่โอน ให้ทีมงานตรวจสอบ
