# LINE OA ของ DealMee เอง (@dealmee, basic ID @238qsjdw)

OA ตัวเดียวทำได้ 2 งาน:

1. **แจ้งเตือนเจ้าของแพลตฟอร์ม**: ส่งข้อความเข้า LINE ส่วนตัวของ super admin เมื่อร้านค้าเติมเงินสำเร็จ หรือมีสลิปเติมเงินรอตรวจ ตั้งค่าที่ `/admin/payment-settings`
2. **บอทตอบร้านค้าและคนที่สนใจ DealMee**: เปิดเป็นร้านชื่อ "DealMee" ในระบบ แล้วให้บอทตอบจากคลังความรู้ เมื่อมีคนสนใจ บอทจะขอชื่อและเบอร์โทร แล้วส่งต่อให้แอดมินทาง LINE

LINE OA ตั้ง Webhook URL ได้แค่อันเดียว ถ้าเปิดใช้งานที่ 2 ต้องตั้ง Webhook URL เป็นของร้าน DealMee
งานที่ 1 ยังทำงานตามปกติ เพราะการส่งแจ้งเตือน (push) ไม่ต้องผ่าน webhook
ส่วนคำสั่ง `/admin-link DM-…` ที่ใช้ผูกเจ้าของแพลตฟอร์ม จะไปถึง webhook ของร้านแทน ซึ่งตั้งแต่ ต.ค. 2569 รองรับแล้ว

## ขั้นตอนเปิดร้าน DealMee

1. **สมัครร้านใหม่**
   - สมัครที่ `https://app.dealmee.app` ด้วยอีเมลที่ยังไม่มีร้าน เพราะ 1 อีเมล = 1 ร้าน และ `praphawach@gmail.com` ผูกกับ Bliss Aurae อยู่แล้ว
   - ตั้งชื่อร้านว่า "DealMee"
2. **ให้ร้านใช้งานได้เต็มที่**: ที่ `/admin/shops` เปลี่ยนแพ็กเกจของร้าน DealMee ให้ใช้งานได้เต็มที่ (เช่น PRO)
3. **ใส่ข้อมูล OA**
   - เข้าแดชบอร์ดของร้าน → ตั้งค่าบอท → แท็บช่องทาง
   - ใส่ Channel Access Token และ Channel Secret ของ @238qsjdw ซึ่งเป็นค่าเดียวกับที่ใส่ใน `/admin/payment-settings`
4. **เปลี่ยน Webhook URL**
   - คัดลอก Webhook URL ของร้านจากแท็บเดียวกัน (`https://www.dealmee.app/api/webhook/<shop_id>`)
   - ไปที่ LINE Developers → channel DealMee → Messaging API → Webhook URL วางแทน `/api/webhook/platform-alerts` แล้วกด Verify
5. **เตรียมความรู้ให้บอท**
   - อัปโหลดคลังความรู้: แพ็กเกจและราคา วิธีสมัคร วิธีเชื่อม LINE/Facebook การเติมเงิน และคำถามที่พบบ่อย
   - ไม่ต้องเพิ่มรายการสินค้า ร้านที่ไม่มีสินค้าจะเข้าโหมดให้ข้อมูลเอง คือตอบคำถาม แล้วเก็บชื่อและเบอร์โทรส่งต่อแอดมิน
6. **ผูกแอดมินร้าน**: ในการ์ด "การแจ้งเตือนแอดมินผ่าน LINE" สแกน QR ด้วย LINE ส่วนตัว แล้วส่ง `/admin-link ADM-…`
7. **ทดสอบ**
   - ทักจากบัญชี LINE อื่นแล้วถามเรื่องแพ็กเกจ
   - ที่ `/admin/payment-settings` กด "ส่งข้อความทดสอบ" แจ้งเตือนเติมเงินต้องยังเข้า LINE ส่วนตัว

## หมายเหตุ

- **ข้อความไหนนับโควตา:** ข้อความที่บอทตอบ (reply) ไม่นับโควตาข้อความของ OA แต่แจ้งเตือนเติมเงินและแจ้งเตือนส่งต่อ (push) นับ
- **ย้อนกลับ:** ถ้าเลิกใช้บอท ให้เปลี่ยน Webhook URL กลับเป็น `/api/webhook/platform-alerts`
- **ข้อความแจ้งเตือน:** เพิ่มเพื่อนกับ OA แล้วจะเห็นทั้งข้อความที่ส่งถึงลูกค้าและแจ้งเตือนของแอดมิน แต่แจ้งเตือนส่งถึงเฉพาะ LINE ที่ผูกเป็นแอดมินเท่านั้น
