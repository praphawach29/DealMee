# ทดลองโมเดลที่โฮสต์เอง — ระยะที่ 1

ระยะนี้เพิ่ม Ollama adapter และเชื่อมกับ evaluation harness ที่ใช้วงจรวางแผนขายจริง แต่ใช้ร้าน สินค้า ลูกค้า และเครื่องมือจำลอง ไม่เปลี่ยนเส้นทาง LINE/Messenger หรือ production และไม่สร้างออเดอร์จริง

## สิ่งที่ทำได้

- ใช้ `EVAL_PROVIDER=ollama` โดยไม่ต้องมี Gemini/OpenAI/OpenRouter API key
- เลือกโมเดลได้ โดยเริ่ม `qwen3:4b` ตามแผนเดิม
- ส่งประวัติ ข้อกำหนดร้าน และคำสั่งเครื่องมือ พร้อมคืนผลเครื่องมือให้โมเดลในรอบถัดไป
- ไม่ลอง provider อื่นเมื่อ Ollama ล้มเหลว รวมถึงตัวประเมินคำตอบเมื่อเปิด `EVAL_JUDGE=1`
- จำกัดเวลาต่อคำขอ 60 วินาที เริ่มบริบท 4096 tokens และจำกัดผลลัพธ์ 1024 tokens
- ไม่ตาม HTTP redirect และไม่ใส่ API key ของบริการภายนอกในคำขอ
- ปฏิเสธชื่อเครื่องมือนอกชุดที่อนุญาต arguments ที่ไม่ใช่ object และคำสั่งหลายเครื่องมือในรอบเดียว เพราะวงจรปัจจุบันรองรับครั้งละหนึ่งเครื่องมือ
- เก็บคะแนน เวลา token และบทสนทนาใน `eval-reports` โดยไม่มีการคิดค่าไฟ/ค่าเครื่องเป็นศูนย์หรืออ้างว่าโมเดลผ่านก่อนวัดจริง

## เตรียม Ollama

ติดตั้งและเปิด Ollama บนเครื่องทดสอบ ดาวน์โหลดโมเดลครั้งแรกด้วย:

```powershell
ollama pull qwen3:4b
```

ใช้ Ollama รุ่นที่รองรับ tool calling และ `think: false` สำหรับโมเดลนี้ ตั้ง `OLLAMA_NO_CLOUD=1` ให้บริการ Ollama และเริ่มบริการใหม่ก่อนใช้ข้อมูลจริง ตัว adapter ปฏิเสธชื่อรุ่น cloud ที่รู้จัก แต่ไม่สามารถพิสูจน์ได้ว่า alias หรือบริการปลายทางไม่ได้ส่งข้อมูลต่อ จึงต้องดูแลนโยบายเครือข่ายและการตั้งค่าฝั่งบริการด้วย

## ทดสอบบน Windows

รันในโฟลเดอร์ DealMee:

```powershell
$env:EVAL_PROVIDER='ollama'
$env:EVAL_MODEL='qwen3:4b'
$env:OLLAMA_BASE_URL='http://127.0.0.1:11434'
$env:OLLAMA_CONTEXT_TOKENS='4096'
$env:OLLAMA_TIMEOUT_MS='60000'
$env:EVAL_LIMIT='5'
$env:EVAL_JUDGE='0'
node --import ./tests/register-hooks.mjs --experimental-strip-types tests/eval/run-live.ts
```

ลบ `EVAL_LIMIT` เพื่อทดสอบทุกกรณี หรือเลือก `EVAL_CATEGORY` / `EVAL_CASE` ตามชุดเดิม อ่านผล JSON และ Markdown ใน `eval-reports` คำสั่งคืน exit code 1 เมื่อมีกรณีไม่ผ่าน

ถ้าเปิดตัวประเมินด้วย `EVAL_JUDGE=1` จะใช้ Ollama เช่นกัน ตั้ง `EVAL_JUDGE_MODEL` เป็นโมเดล local เท่านั้น ไม่ควรใช้โมเดลเดียวกันเป็นหลักฐานคุณภาพเพียงอย่างเดียว ควรให้คนตรวจคำตอบด้วย

## VPS

ตัว adapter ใช้ `OLLAMA_BASE_URL` ที่เป็น HTTPS origin ได้ จึงไม่ผูกกับคอมพิวเตอร์เครื่องนี้ สำหรับบริการ HTTP ในเครือข่ายส่วนตัวใช้ secure tunnel มาที่ loopback แทน ไม่เปิดพอร์ต 11434 สู่สาธารณะ คู่มือระยะนี้ยังไม่ติดตั้ง reverse proxy, authentication, VPN หรือเช่า VPS ให้

## ขอบเขตความเป็นส่วนตัว

การทดสอบนี้ใช้ข้อมูลสมมติและเครื่องมือจำลอง ไม่ได้ทำให้ทั้ง DealMee เป็น local-only: production, embedding, document processing, skill extraction, ฐานข้อมูล และบริการช่องทางยังต้องตรวจและปรับแยกก่อนใช้ข้อมูลร้านจริง ห้ามถือว่าการผ่านชุดทดสอบเท่ากับอนุมัติเปิดขายจริง

## เกณฑ์ก่อนระยะต่อไป

1. รันทดสอบโมเดลจริงและตรวจคำตอบภาษาไทย ราคา สต๊อก การเรียกเครื่องมือ และการส่งต่อคน
2. เพิ่มการตรวจ arguments ตาม schema เต็มรูปแบบก่อนต่อเครื่องมือที่มีผลจริง
3. ตรวจกรณีข้อมูลต่างร้านไม่ปน และ prompt injection โดยใช้ข้อมูลจำลอง
4. วัดการตัดบริบท: 4K เป็นเพียงจุดเริ่ม หาก prompt และ tool schema ยาว ต้องปรับการคัดข้อมูลหรือบริบทแล้วทดสอบใหม่
5. วัดคิวหลายร้าน เวลา p50/p95 และหน่วยความจำ ก่อนซื้อเครื่องหรือเลือก GPU VPS
6. แยก provider selection และนโยบาย local-only ของ production ให้ครอบคลุมทุกเส้นทาง AI พร้อม idempotency ของออเดอร์ ก่อนเปิดวงจำกัด
